**Overview:** Marvel Tic Tac Toe is a two-player strategy game inspired by the classic Gobblet Gobblers, reimagined with a Marvel themed interface.

**Features**

- 🎮 Two-player gameplay with modified tic-tac-toe mechanics

- 🦸 Marvel-themed user interface and game elements

- ⚙️ Adjustable game complexity and customizable settings

**Tech Stack**
- Language: Java
- Design: UI mockups and user flow planning designed via Figma

**How to Run:**
Clone the repository
Open the project in your preferred Java IDE
Compile and run the main application file

**Author:**
Developed as part of a software development project focusing on game logic, UI design, and SDLC best practices.
